# Star Wars

React Native app for looking up Planets, Spaceships, and Films.

iOS and web use bottom tabs. Android uses a navigation drawer. Each screen is laid out with Flexbox and shows its name. A search box at the top of every screen opens a dialog with the term that was entered. Each list scrolls, and swiping an item opens a dialog with that item's text. Rows slide in from the left when they first appear. A galaxy photo at the top of every screen stays behind a placeholder until it finishes loading.

## Run

```bash
npm install
npx expo start
```

Then open the project in Expo Go, an emulator, or the browser.
