# Star Wars

React Native app for looking up Planets, Spaceships, and Films.

iOS and web use bottom tabs. Android uses a navigation drawer. Each screen is laid out with Flexbox and shows its name.

## Run

```bash
npm install
npx expo start
```

Then open the project in Expo Go, an emulator, or the browser.

## Expo Snack

https://snack.expo.dev/A7qpdP6ecC5SyUxTWKI9D

Use the Web or iOS preview for the bottom tabs. Switch the preview to Android for the drawer.
